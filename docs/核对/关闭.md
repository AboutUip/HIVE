## `close`

关闭已打开的存储。

### 签名

```javascript
hive.close()
```

### 参数

无。

### 返回

没有返回值。

### 抛出

关闭之后，这个对象再调用会抛出 `库已关闭`。

### 调用返回时

同一个数据目录可以再 `createHive()`，从 `state.json` 接着上次的局面。进程内的不可达、断链、库损坏标记和别名核对次数不写入库，重新打开后清零。

### 例子

```javascript
hive.close()
const again = createHive({ dataDir: './data' })
again.getState()
```

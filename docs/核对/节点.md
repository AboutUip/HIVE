## `join`

增加一台服务节点。

### 签名

```javascript
const { nodeId } = hive.join({ region, name })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `region` | 字符串 | 是 | 区域。 |
| `name` | 字符串 | 否 | 省略时用「区域名 + 节点」。 |

### 返回

普通结果，另含 `nodeId`。编号和地址按配置里的 `newNodeId`、`newNodeIp` 生成，别名等于编号。默认第一台新节点是 `svc-4`，地址 `10.4.0.1`。

### 抛出

| 条件 | `message` |
| --- | --- |
| 没有区域 | `新节点要落在一个区域` |
| 没有正在服务的节点 | `现在没有正在服务的节点可以提供索引` |

### 调用返回时

状态为对齐中。索引从当前负载最低的正在服务节点拉来，并临时加上那台节点自己的数据。临时表不写回来源节点。新节点不在任何灾备的负责范围里。

负载是本机数据份数。份数相同，取编号较小的一台。无法访问或数据库已坏的节点不参与。

### 例子

```javascript
const { nodeId } = hive.join({ region: '西南', name: '西南节点' })
```

## `ready`

结束对齐。

### 签名

```javascript
hive.ready(nodeId)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 对齐中的服务节点。 |

### 返回

普通结果。

### 抛出

不是对齐中的服务节点时抛出 `西南节点不在对齐过程中`。

### 调用返回时

状态改为正在服务。缓冲区里的地址写入它的索引。上次上报记为当前拍。

### 例子

```javascript
hive.ready(nodeId)
```

## `setCovers`

设置一台灾备的负责范围，替换原列表。

### 签名

```javascript
hive.setCovers(drId, nodeIds)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `drId` | 字符串 | 是 | 灾备编号。 |
| `nodeIds` | 字符串数组 | 是 | 服务节点编号。空数组表示谁也不负责。 |

不是服务节点的 id 会被丢掉。

### 返回

普通结果。

### 抛出

目标不是灾备时抛出 `只有灾备节点需要声明负责范围`。

### 调用返回时

只改声明，不立刻重放旧数据，也不自动走一拍灾备。新范围内的新日志要之后再 `advance('dr')` 才会进入。已经住在范围外的记录，要等这个键下一次被整理时才会离开。

### 例子

```javascript
hive.setCovers('dr-1', ['svc-a', 'svc-b'])
hive.advance('dr')
```

## `changeIp`

把一台节点的当前 IP 改成新值。

### 签名

```javascript
hive.changeIp(nodeId, ip)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 节点。 |
| `ip` | 字符串 | 是 | 新地址。核对配置里的默认值是 IPv4，例如 `10.1.0.9`。 |

### 返回

普通结果。

### 抛出

空字符串抛出 `要写上新的地址`。

### 调用返回时

中央的节点记录、全局地址、缓冲区和待补送地址一起改。已经在各服务节点上的地址副本不改，仍用旧 IP。下次读取发现旧 IP 不通时，按别名更新。别名不变。

### 例子

```javascript
hive.changeIp('svc-a', '10.1.0.9')
```

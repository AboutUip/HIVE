## `getState`

读出当前局面。不推进，不写入。

### 签名

```javascript
const state = hive.getState()
```

### 参数

无。

### 返回

```javascript
{
  tick,
  syncPeriod,
  drPeriod,
  tolerance,
  retention,
  nextSyncIn,
  nextDrIn,
  actor: { userId, nodeId },
  nodes,
  indexMaster,
  logs,
  logCount,
  unorganizedLogCount,
  mergeJob,
  events
}
```

| 字段 | 说明 |
| --- | --- |
| `tick` | 当前拍，从 0 开始。 |
| `syncPeriod` | 全局上报周期。 |
| `drPeriod` | 灾备周期。 |
| `tolerance` | 容错拍数。 |
| `retention` | 是否留档。 |
| `nextSyncIn` | 按全局周期估算的下一拍上报。不按某一台单独改过的周期计算。 |
| `nextDrIn` | 按全局灾备周期估算的下一拍整理。 |
| `actor` | 当前用户和他所在的服务节点。 |
| `nodes` | 全部节点，形状见下面两张表。 |
| `indexMaster` | 中央的全局地址。 |
| `logs` | 最多 12 条，中央还没整理完的日志。 |
| `logCount` | 还在中央的日志条数。 |
| `unorganizedLogCount` | 与 `logCount` 相同。还在中央的每一条都还没用完。 |
| `mergeJob` | `null`，或 `{ lostId, targetId, startedTick }`。 |
| `events` | 最多 60 条，按发生顺序。 |

`indexMaster` 的每一行：`user_id`、`data_key`、`node_id`、`ip`、`alias`、`updated_at`、`suspended`。`suspended` 为 `0` 或 `1`。没有值字段。

`events[].kind` 包括 `info`、`write`、`delete`、`read`、`reject`、`sync`、`dr`、`drop`、`join`、`ready`、`lose`、`merge`。

`updated_at` 是 UTC 的 ISO 字符串，例如 `2026-01-01T00:00:00.000Z`。比较时更晚的字符串更大。

服务节点：

| 字段 | 说明 |
| --- | --- |
| `id` `name` `role` `region` `ip` `alias` | 身份与地址。`role` 为 `service`。 |
| `status` | `up`、`joining`、`merging`、`lost`。 |
| `covers` | 服务节点恒为空数组。 |
| `reportPeriod` `lastReport` | 这台节点的上报周期，以及上次成功上报的拍。 |
| `reachable` | 是否被标成可访问。 |
| `dbBroken` | 库是否被标成不可达。 |
| `fragmentCount` | 本机数据份数。库不可达时为 `null`。 |
| `fragments` | `user_id`、`data_key`、`value`、`updated_at`。 |
| `outbox` | 待上报。另有 `id`、`op`。`op` 为 `put` 或 `delete`。 |
| `indexEntries` | 持久地址副本。字段与全局地址相同。 |
| `buffer` | 对齐期间暂存的地址。另有 `target_node`、`op`。 |

灾备节点在身份字段之外有 `covers`（服务节点 id 数组）和 `records`。记录字段为 `user_id`、`data_key`、`value`、`updated_at`、`home_node`、`organized_tick`。

### 抛出

| 条件 | `message` |
| --- | --- |
| 已关闭 | `库已关闭` |
| 还没有局面 | `这个目录还没有局面，先 reset()` |

### 调用返回时

不改存储。库被标成不可达的节点，本地数据列表为空，并带 `dbBroken: true`。

### 例子

```javascript
const state = hive.getState()
const north = state.nodes.find((node) => node.id === 'svc-a')
```

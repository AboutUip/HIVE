## `setWindows`

把全局上报周期和灾备周期改成这两个正整数，单位是拍。

### 签名

```javascript
hive.setWindows(syncPeriod, drPeriod)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `syncPeriod` | 整数 | 是 | 不小于 1。 |
| `drPeriod` | 整数 | 是 | 不小于 1。 |

### 返回

普通结果。

### 抛出

| 条件 | `message` |
| --- | --- |
| 上报周期不合法 | `上报窗口至少是 1 拍` |
| 灾备周期不合法 | `灾备窗口至少是 1 拍` |

### 调用返回时

每台服务节点的上报周期改成同一个数。「上次上报」记成当前拍，重试次数清零。这就是改窗口通知：通知之后的空档不算漏报。

### 例子

```javascript
hive.setWindows(4, 12)
```

## `setReportPeriod`

只改这一台服务节点的上报周期。

### 签名

```javascript
hive.setReportPeriod(nodeId, period)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `period` | 整数 | 是 | 不小于 1 的拍数。 |

### 返回

普通结果。

### 抛出

不是服务节点时抛出 `只有服务节点有上报周期`。周期不合法时抛出 `上报窗口至少是 1 拍`。

### 调用返回时

只改这一台，并发送改窗口通知。灾备周期不变。`state.nextSyncIn` 仍按全局周期计算。

### 例子

```javascript
hive.setReportPeriod('svc-a', 5)
```

## `setRetention`

选择整理之后是否把日志留成文件。

### 签名

```javascript
hive.setRetention(enabled)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 布尔 | 是 | `true` 留档，`false` 不留。 |

### 返回

普通结果。

### 抛出

没有局面或已关闭时，与其他方法相同。

### 调用返回时

`true` 时，日志整理进灾备之后仍从中央删除，并在删除前把每一条追加进留档文件。每行一个 JSON：`userId`、`key`、`value`、`op`、`updatedAt`、`source`。

`false` 时只删除，不写文件。`reset()` 之后默认为 `false`。文件路径是创建时的 `retentionFile`。

### 例子

```javascript
hive.setRetention(true)
hive.advance('dr')
```

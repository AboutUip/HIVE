[文档目录](../README.md)。行为见 [写入](../方案/写入.md)、[读取](../方案/读取.md)、[删除](../方案/删除.md)、[索引](../方案/索引.md)。

除特别注明外，成功时返回 `{ message, state }`。`state` 与 [getState](局面.md) 相同。失败时抛出 `Error`，`error.expose === true`，说明在 `error.message`。

一次 `write` 或 `remove` 里，每个键单独提交。后面的键出错时，前面已经提交的键还在。

## `write`

在指定服务节点上写下若干键。

### 签名

```javascript
hive.write({ nodeId, userId, entries })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点编号。 |
| `userId` | 字符串 | 是 | 用户。 |
| `entries` | 数组 | 是 | `{ key, value }`。键和值去掉首尾空白。值不能为空。 |

### 返回

普通结果。成功时也会把 `state.actor` 改成这个用户和这台节点。

### 抛出

| 条件 | `message` |
| --- | --- |
| 没有用户 | `先写上用户是谁` |
| 没有内容 | `这次没有要写入的内容` |
| 没有键名 | `每一份数据都要有名字` |
| 值为空 | `A 还没有内容` |
| 不是服务节点 | `只能往服务节点写` |
| 已挂失 | `华北节点已挂失，不能在这里写入` |
| 对齐中 | `华北节点还在对齐索引，还不能写入` |
| 其他状态 | `华北节点现在不能写入` |
| 库已被标成不可达 | `华北节点的数据库不可达，已申请挂失` |

只能写给状态为正在服务或正在装入的服务节点。

### 调用返回时

数据在这台节点的库里，并进入待上报。中央确认前不会从队列删除。时间由这台节点的 `now` 产生。

### 例子

```javascript
hive.write({ nodeId: 'svc-a', userId: '甲', entries: [{ key: 'A', value: '甲一' }] })
```

## `read`

从指定节点读取若干键。

### 签名

```javascript
const { results } = hive.read({ nodeId, userId, keys })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 从这台服务节点的视角读。 |
| `userId` | 字符串 | 是 | 用户。 |
| `keys` | 字符串数组 | 是 | 键。 |

### 返回

普通结果，另含 `results`。与 `keys` 一一对应。某一键是拒绝或挂起时，整个调用仍然成功。

| `source` | 含义 |
| --- | --- |
| `local` | 本机库里有。`storedLocally` 为 `true`。 |
| `remote` | 按地址取回，没有写入本机。`storedLocally` 为 `false`。 |
| `rejected` | 视为没有。包括索引里没有、对方已经没有、别名核对后仍不可达。 |
| `suspended` | 地址已挂起，或目标已挂失。请求没有发出。 |

取到值时还有 `value`、`fromNodeId`、`fromIp`、`via`。`via` 为 `local`、`ip` 或 `alias`。`alias` 表示原来的 IP 不通，已经按别名核对过一次，并更新了这台节点上同一别名的地址。

`hive.aliasLookups` 是进程内计数。每次因 IP 不通而核对别名加 1。IP 可用时不加。重新打开后清零。

### 抛出

| 条件 | `message` |
| --- | --- |
| 不是服务节点 | `只能向服务节点读取` |
| 已挂失 | `华北节点已挂失，请求停在原地` |
| 对齐中 | `华北节点还没投入服务` |
| 没有用户 | `先写上用户是谁` |
| 没有键 | `先指定要读取的键` |

### 调用返回时

成功读取也会更新 `state.actor`。远程值不写入本机。

### 例子

```javascript
hive.advance('sync')
const read = hive.read({ nodeId: 'svc-b', userId: '甲', keys: ['A'] })
```

## `remove`

在持有这些数据的节点上删除。

### 签名

```javascript
hive.remove({ nodeId, userId, keys })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 必须是持有该键的服务节点。 |
| `userId` | 字符串 | 是 | 用户。 |
| `keys` | 字符串数组 | 是 | 键。 |

### 返回

普通结果。

### 抛出

本机没有该键时抛出 `华北节点上没有 甲 的 A，不能在这里删除`。用户或键列表不合法时，与 `write` 的对应说明相同。

### 调用返回时

本机数据和本机对应地址立即去掉。删除日志留在待上报里。上报之后其他节点的地址才会去掉。下一次灾备整理才会去掉灾备记录。

### 例子

```javascript
hive.remove({ nodeId: 'svc-a', userId: '甲', keys: ['A'] })
```

## `list`

列出这台服务节点上的完整地址。

### 签名

```javascript
const { rows } = hive.list({ nodeId, userId })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `userId` | 字符串 | 否 | 省略时列出全部用户。 |

### 返回

普通结果，另含 `rows`。每一行含 `user_id`、`data_key`、`node_id`、`ip`、`alias`、`updated_at`、`suspended`。没有值。

行来自一张临时表：持久索引加上本机库里的数据。同一键以本机库为准。

### 抛出

| 条件 | `message` |
| --- | --- |
| 已挂失 | `华北节点已挂失` |
| 不是服务节点 | `只能向服务节点要索引` |

对齐中的节点可以列它已经拿到的临时索引。

### 调用返回时

持久索引的条数不变。

### 例子

```javascript
hive.list({ nodeId: 'svc-a', userId: '甲' })
```

## `setActor`

记下当前用户站在哪台服务节点。

### 签名

```javascript
hive.setActor(nodeId, userId)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `userId` | 字符串 | 是 | 用户。 |

### 返回

普通结果。

### 抛出

不是服务节点时抛出 `人只能站在服务节点上`。没有用户时抛出 `先写上用户是谁`。

### 调用返回时

只改 `state.actor`，不改变数据所在。`write` 和 `read` 成功时也会改写这组记录。

### 例子

```javascript
hive.setActor('svc-b', '甲')
```

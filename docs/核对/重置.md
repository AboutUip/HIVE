## `reset`

清空已有数据，再按配置播种。

### 签名

```javascript
const result = hive.reset()
```

### 参数

无。配置用创建时的 `config` 或 `configPath`。每次调用都重新读取。

### 返回

普通结果：

```javascript
{
  message: '给人看的一句说明',
  state: {}
}
```

`state` 与 [getState](局面.md) 相同。

### 抛出

配置不合法时，在清空之前抛出，目录里的旧局面还在。存储失败时抛出存储的错误。

### 调用返回时

拍数为 0。节点、负责范围、上报周期、灾备周期、容错和新节点序号都来自这次读到的配置。留档关闭。进程内的不可达、断链、库损坏标记和别名核对次数清零。

Windows 上若使用 SQLite，关闭后文件可能仍被锁住。`reset()` 会在重新打开后清空表，不依赖把文件删掉。

### 例子

```javascript
hive.reset()
hive.write({ nodeId: 'svc-a', userId: '甲', entries: [{ key: 'A', value: '甲一' }] })
```

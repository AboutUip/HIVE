[文档目录](../README.md)。行为见 [挂失](../方案/挂失.md)、[恢复](../方案/恢复.md)、[回来](../方案/回来.md)。

同一时间只有一项装入。`state.mergeJob` 为 `null`，或为 `{ lostId, targetId, startedTick }`。接替节点在装入期间的状态是正在装入。它可以继续读写自己的数据。指向挂失节点的读取结果是 `suspended`。

## `lose`

中央强制挂失。

### 签名

```javascript
hive.lose(nodeId, options)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `options.cause` | 字符串 | 否 | 原因。默认 `中央强制挂失`。 |

### 返回

普通结果。`message` 里会说明装入到了哪一台，或说明已经回退。

### 抛出

| 条件 | `message` |
| --- | --- |
| 不是服务节点 | `只能挂失服务节点` |
| 已经挂失 | `华北节点已经挂失` |
| 还在对齐 | `华北节点还没投入服务，不用走挂失` |
| 已有别的装入 | `已经有节点在融合，先完成这次再挂失下一台` |
| 没有可接替节点 | `没有还能接替的服务节点` |

挂失的正是当前接替节点时，不抛出，改为回退并把它也标成挂失。

### 调用返回时

选择一台正在服务的低负载节点作为接替，把它标为正在装入，挂起指向挂失节点的地址。待上报队列留在挂失节点上，不会补交。接着会尝试完成装入。接替失败时返回回退说明，不抛出。

### 例子

```javascript
hive.advance('dr')
hive.lose('svc-a')
```

## `applyLoss`

节点自己申请挂失。

### 签名

```javascript
hive.applyLoss(nodeId, cause)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `cause` | 字符串 | 否 | 默认 `节点申请挂失`。 |

### 返回

普通结果。已经挂失时不抛出，说明里是「已经挂失」。

### 抛出

与 `lose` 相同，但已经挂失时不抛出。

### 调用返回时

后续与 `lose` 相同。

### 例子

```javascript
hive.applyLoss('svc-a', '数据库不可达')
```

## `reportRuntime`

节点报告运行错误并申请挂失。

### 签名

```javascript
hive.reportRuntime(nodeId, reason)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 服务节点。 |
| `reason` | 字符串 | 否 | 默认 `运行报错`，并作为挂失原因。 |

### 返回

与 `applyLoss` 相同。

### 抛出

与 `applyLoss` 相同。

### 调用返回时

立即申请挂失，不等下一拍。

### 例子

```javascript
hive.reportRuntime('svc-a', '运行报错')
```

## `finishMerge`

完成当前装入。

### 签名

```javascript
hive.finishMerge()
```

### 参数

无。

### 返回

普通结果。接替失败时，`message` 说明回退，不抛出。

### 抛出

没有装入时抛出 `现在没有正在融合的节点`。

### 调用返回时

若中央还留着日志，先整理进灾备并提交，再按灾备装入。装入本身是另一次提交：接替节点上严格更新的本地数据保留，其余写入灾备的值，地址改到接替节点并取消挂起，接替节点恢复为正在服务。

这次提交完成前进程停掉，装入不会留下半套地址。`mergeJob` 还在，再次调用会接着装。

接替节点此时无法访问、数据库已坏，或装入中途失败：这次装入提交会撤销，然后把接替节点标成挂失，清空 `mergeJob`。原来的挂失保留。此前已经整理进灾备的日志留下。

### 例子

```javascript
hive.lose('svc-a')
hive.finishMerge()
```

`lose` 已经会尝试装入。`finishMerge` 用于装入还停在半路、需要再完成一次的时候。

## `recover`

对一台已经挂失的服务节点，重新选择低负载节点开始装入。

### 签名

```javascript
hive.recover(nodeId)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 已经挂失的服务节点。 |

### 返回

普通结果，内容与这次 `finishMerge` 相同。

### 抛出

| 条件 | `message` |
| --- | --- |
| 还没挂失，或不是服务节点 | `只能对已经挂失的服务节点继续恢复` |
| 已经有装入 | `已经有节点在融合` |
| 没有可接替节点 | `没有还能接替的服务节点` |

### 调用返回时

数据仍来自灾备。用于接替失败之后继续转移所有权。

### 例子

```javascript
hive.recover('svc-a')
```

## `rejoin`

挂失节点回来：清空旧编号，再按新节点加入。

### 签名

```javascript
const { nodeId } = hive.rejoin(nodeId, options)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `nodeId` | 字符串 | 是 | 已挂失的服务节点。 |
| `options.region` | 字符串 | 否 | 省略时用旧区域。 |
| `options.name` | 字符串 | 否 | 省略时用「旧区域 + 新节点」。 |

### 返回

普通结果。其中的 `nodeId` 是新编号。

### 抛出

| 条件 | `message` |
| --- | --- |
| 不是已挂失的服务节点 | `只有挂失节点回来时才清空并作为新节点` |
| 当前装入仍涉及这台节点 | `融合尚未结束，先处理完这次装入` |

### 调用返回时

旧编号保持挂失，库是空的。新编号的状态为对齐中，索引来自当前负载最低的正在服务节点。

### 例子

```javascript
const again = hive.rejoin('svc-a', { region: '华北' })
hive.ready(again.nodeId)
```

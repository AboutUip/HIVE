## 健康端点

三个进程都有 `GET /v1/health`，带集群令牌。

### 返回

中央：`role`、`ok`、`now`、`acceptedLogs`、`nodes`（每台的 `id`、`status`、`ip`、`last_report`、`retries`）、`mergeJob`、`logCount`、`pendingCount`。

服务节点：`role`、`ok`、`id`、`name`、`status`（`up` 或 `joining`）、`counters`（`writes`、`reads`、`reports`）、`fragments`、`outbox`、`indexes`、`readBreakers`（熔断中的别名列表）。

灾备：`role`、`ok`、`id`、`name`、`covers`、`records`。

### 例子

```javascript
import { call, parseAddress } from 'hive'

const { host, port } = parseAddress(central.address)
const health = await call({ host, port, method: 'GET', path: '/v1/health', token })
```

## TLS

`startCentral`、`startService`、`startDr` 都接受 `tls` 参数。给了它，监听用 HTTPS，发出的调用也走 HTTPS。整套集群要么都开，要么都不开。

### 参数

| 字段 | 说明 |
| --- | --- |
| `key` | 服务端私钥，PEM 字符串或 Buffer。 |
| `cert` | 服务端证书。 |
| `ca` | 验证对端的 CA。自签证书时可以填自己的 `cert`。 |
| `servername` | 可选。对端主机名与 IP 不一致时指定。 |
| `rejectUnauthorized` | 可选。默认 `true`，不要在生产里关。 |

`callTimeoutMs` 给每个进程的对外调用设超时，默认 `2000`。中央向节点推送（索引、挂起、装入、灾备整理）会自动重试一次。

## 背压与熔断

- 服务节点的待上报条数到 `maxOutbox`（默认 `10000`）后，`write` 和 `remove` 抛出 `待上报积压超过上限，中央可能联系不上`。这是有意为之：积压越深，挂失时一次丢得越多。
- 读路径上连续取不到同一别名 `readBreakerFails` 次（默认 `3`）后，`readBreakerCooldownMs`（默认 `30000`）内跳过直连、先向中央要一次新地址。熔断中的别名出现在 health 的 `readBreakers` 里。

## `rebuildCentralIndexes`

中央的局面文件丢了之后，从各服务节点的碎片和灾备记录重建中央索引，并把重建好的索引推给活着的服务节点。值按时间取各处的较新一份。

### 签名

```javascript
import { rebuildCentralIndexes } from 'hive'

const result = await rebuildCentralIndexes({ dataDir, token, nodes })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `dataDir` | 字符串 | 是 | 中央的数据目录。 |
| `token` | 字符串 | 是 | 集群令牌。 |
| `nodes` | 数组 | 库是空的时候必须 | `{ id, name, role, region, ip, alias, covers }` 清单，用来重建节点表。 |
| `store` | 对象 | 否 | 自己的存储。不传时用 `FileStore`。 |

### 返回

`{ masters, pushed, collected }`：写回中央的索引条数、推到了几台服务节点、一共收集到的键。

### 抛出

中央的库是空的且没有 `nodes` 时，抛出 `中央的库是空的，要带上节点清单`。

### 调用返回时

- 重建只增不删：原有索引里重建没碰到的行保持原样。
- 连不上的节点跳过，不会打断整体重建。
- 家里已挂失的键，索引带 `suspended: 1` 重建。

### 例子

```javascript
const result = await rebuildCentralIndexes({
  dataDir: './data/central',
  token,
  nodes: [
    { id: 'svc-a', name: '华北节点', role: 'service', region: '华北', ip: '10.1.0.1:7100', alias: 'svc-a' }
  ]
})
```

仓库里的 `scripts/rebuild-index.js` 用同一个函数做成命令行。

## `startDr`

启动一台灾备，并向中央登记这次绑定的地址和负责范围。

### 签名

```javascript
import { startDr } from 'hive'

const dr = await startDr(options)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `dataDir` | 字符串 | 是 | 这台灾备自己的数据目录。 |
| `token` | 字符串 | 是 | 与中央相同的令牌。 |
| `central` | `{ host, port }` | 是 | 中央的地址。`port` 用中央的 `http.port`。 |
| `id` | 字符串 | 是 | 必须与中央 `nodes` 里的这台灾备相同。 |
| `name` | 字符串 | 是 | 必须能对上中央里的这台节点。 |
| `region` | 字符串 | 是 | 区域名。 |
| `covers` | 字符串数组 | 是 | 负责哪些服务节点。登记时会写到中央。 |
| `alias` | 字符串 | 否 | 省略时等于 `id`。 |
| `host` | 字符串 | 否 | 监听地址。默认 `127.0.0.1`。 |
| `port` | 整数 | 否 | 监听端口。默认 `0`。 |
| `helloTimeoutMs` | 整数 | 否 | 连不上中央时最多再试这么久。默认 `5000`。 |
| `store` | 对象 | 否 | 自己的存储。不传时使用 `FileStore`。 |
| `tls` | 对象 | 否 | TLS 配置。给了它监听走 HTTPS，发出的调用也走 HTTPS。见 [运维](运维.md)。 |
| `callTimeoutMs` | 整数 | 否 | 向中央调用的超时。默认 `2000`。 |

### 返回

灾备对象。`close()` 停掉监听并关闭存储。

### 抛出

| 条件 | `message` |
| --- | --- |
| 没有 `dataDir` | `要指定数据目录` |
| 没有 `token` | `集群令牌不能是空的` |
| `central` 缺少主机或端口 | `要写上中央的地址` |
| 缺少编号、名称或区域 | `灾备要有编号、名称和区域` |
| 超时仍联系不上中央 | 最后一次连接错误，例如 `无法连接` |
| 中央没有这个编号 | `没有这台节点` |

### 调用返回时

中央已经记下这台灾备的 `主机:端口` 和 `covers`。之后中央整理日志时，会把负责范围内的稳定数据交给它。负责范围外的键，在下次整理到这个键时离开这台灾备。

只改 `covers`、又没有这个键的新日志，不会立刻重扫已经收好的记录。

### 例子

```javascript
const dr = await startDr({
  dataDir: './data/dr',
  token: '集群令牌',
  id: 'dr-1',
  name: '灾备甲',
  region: '集中',
  covers: ['svc-a', 'svc-b'],
  host: '127.0.0.1',
  central: { host: central.host, port: central.http.port }
})
```

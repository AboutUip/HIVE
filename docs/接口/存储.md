## `FileStore`

默认存储。中央、服务节点、灾备各自一个目录，各写一份 `state.json`。

### 签名

```javascript
import { FileStore } from 'hive'

const store = new FileStore(dataDir)
```

传给 `startCentral`、`startService`、`startDr` 或 `createHive` 的 `store`。不传时，这些函数自己 `new FileStore(dataDir)`。

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `dataDir` | 字符串 | 是 | 目录。文件是其中的 `state.json`。 |

### 返回

存储对象。实现 [下面的方法](#store_methods)。

### 抛出

目录不可写、或 `state.json` 不是 JSON 时，由文件系统或 `JSON.parse` 抛出。

### 调用返回时

一次最外层 `transaction` 成功或失败之后，都会把内存里的局面写成临时文件，刷到磁盘，再替换 `state.json`。失败时内存已经回到这次事务之前，写出的也是那一版。进程在替换文件之前停掉，重开后看到的是上一次成功替换的局面。

### 例子

```javascript
import { FileStore, startService } from 'hive'

const node = await startService({
  dataDir: './data/svc-a',
  store: new FileStore('./data/svc-a'),
  token: '集群令牌',
  id: 'svc-a',
  name: '华北节点',
  region: '华北',
  central: link
})
```

## `MemoryStore`

只活在这个进程里的存储。核对引擎时用来证明逻辑不绑在某一种文件上。

### 签名

```javascript
import { MemoryStore } from 'hive'

const store = new MemoryStore()
```

### 参数

无。

### 返回

存储对象。

### 抛出

关闭之后再读写，抛出 `库已关闭`。

### 调用返回时

事务用内存快照回滚。`close()` 只关掉可用标记，数据还在这个对象上。进程结束，数据就没了。它不会写出 `state.json`。

### 例子

```javascript
import { MemoryStore, createHive } from 'hive'

const store = new MemoryStore()
const hive = createHive({ dataDir: dir, store })
```

同一个 `store` 可以在 `close()` 之后交给下一次 `createHive`，局面还在。

## `SqliteStore`

可选存储。需要 Node.js 22.5 或更高版本。使用 Node 自带的 `node:sqlite`。

### 签名

```javascript
import { SqliteStore } from 'hive/sqlite'

const store = new SqliteStore(dataDir)
```

主入口 `hive` 不加载这个模块。

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `dataDir` | 字符串 | 是 | 目录。数据库文件是其中的 `hive.db`。 |

核对整个集群时，中央、各服务节点和灾备在这一个文件里，这样一次提交能盖住装入时要同时改的那些记录。生产里每个进程仍应使用自己的目录。

### 返回

存储对象。

### 抛出

当前 Node 没有 `node:sqlite` 时，加载 `hive/sqlite` 失败。

### 调用返回时

使用 WAL，同步级别为 FULL。事务可嵌套：内层失败只撤销内层。Windows 上关闭之后文件可能仍被锁住。`reset()` 会在重新打开后清空表，不依赖把文件删掉。

### 例子

```javascript
import { createHive } from 'hive'
import { SqliteStore } from 'hive/sqlite'

const hive = createHive({
  dataDir: './data',
  store: new SqliteStore('./data')
})
```

## `STORE_METHODS`

自己的数据库要实现的方法名。缺任何一个，创建核对对象时抛出 `存储缺少方法：…`。

### 签名

```javascript
import { STORE_METHODS } from 'hive'
```

### 参数

无。它是一个字符串数组。

### 返回

方法名：`open`、`close`、`isOpen`、`reset`、`hasLayout`、`inTransaction`、`transaction`、`getMeta`、`setMeta`、`addEvent`、`listEvents`、`insertNode`、`updateNode`、`getNode`、`listNodes`、`insertLog`、`listLogs`、`listRecentLogs`、`countLogs`、`deleteLogs`、`hasReceipt`、`insertReceipt`、`getMaster`、`putMaster`、`deleteMaster`、`listMasters`、`suspendMasters`、`updateMasterIp`、`countSuspendedMasters`、`getBuffer`、`insertBuffer`、`updateBuffer`、`listBuffers`、`deleteBuffers`、`suspendBuffers`、`updateBufferIp`、`getPending`、`putPending`、`listPending`、`deletePending`、`suspendPending`、`updatePendingIp`、`getMergeJob`、`insertMergeJob`、`deleteMergeJob`、`getFragment`、`putFragment`、`deleteFragment`、`listFragments`、`countFragments`、`getIndex`、`putIndex`、`deleteIndex`、`listIndexes`、`updateIndexIpByAlias`、`suspendIndexes`、`listOutbox`、`insertOutbox`、`deleteOutbox`、`countOutbox`、`getRecord`、`putRecord`、`deleteRecord`、`listRecords`、`listRecordsByHome`、`updateRecordHome`、`deleteRecordHome`、`latestStamp`、`clearHolder`。

### 抛出

无。缺方法是在 `createHive` 时检查的。

### 调用返回时

`reset()` 必须把已有数据清掉并保持可写。`transaction(fn)` 要能嵌套：内层失败只撤销内层，外层还在。`hasLayout()` 在写入过 `tick` 之后返回真。

### 例子

```javascript
import { STORE_METHODS, createHive } from 'hive'

const hive = createHive({ dataDir: './data', store })
```

`store` 上要有 `STORE_METHODS` 里的每一个函数。

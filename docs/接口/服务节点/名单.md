## `list`

在持久索引上临时补上本机库里的数据。同一键以本机库为准。用完即弃，不写回持久索引。

### 签名

```javascript
const { rows } = node.list({ userId })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `userId` | 字符串 | 否 | 只列这个用户。省略时列出全部用户。 |

### 返回

`rows` 的每一行：

| 字段 | 说明 |
| --- | --- |
| `user_id` | 用户。 |
| `data_key` | 键。 |
| `node_id` | 数据所在节点。本机库补上的行指向自己。 |
| `ip` | `主机:端口`。 |
| `alias` | 别名。 |
| `updated_at` | UTC 的 ISO 字符串。 |
| `suspended` | `0` 或 `1`。挂起为 `1`。 |

没有 `value`。

### 抛出

存储抛错时，错误交给调用方。对齐中的节点可以列，不抛出「还没投入服务」。

### 调用返回时

持久索引的条数不变。本机库不变。

### 例子

林夏在华北写下城市和电话，尚未上报：

```javascript
const listed = north.list({ userId: '林夏' })
```

两行的 `node_id` 都是华北，因为它们来自本机库，而这次派发还没发生，持久索引里也还没有它们。

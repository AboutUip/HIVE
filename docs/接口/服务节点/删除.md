## `remove`

立刻去掉本机上的这些键，并留下删除日志等待上报。

### 签名

```javascript
await node.remove({ userId, keys })
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `userId` | 字符串 | 是 | 用户是谁。 |
| `keys` | 字符串数组 | 是 | 要删除的键。只能删本机库里有的键。 |

### 返回

```javascript
{ removed: ['电话'] }
```

### 抛出

| 条件 | `message` |
| --- | --- |
| 还在对齐 | `华北节点还没投入服务` |
| 没有用户 | `先写上用户是谁` |
| `keys` 为空或不是数组 | `先指定要删除的键` |
| 某一项没有键名 | `每一份数据都要有名字` |
| 本机没有这个键 | `华北节点上没有 林夏 的 电话，不能在这里删除` |

后面的键抛出时，前面已经删除的键保持删除。

### 调用返回时

本机碎片和本机上这个键的地址已经去掉。删除日志在待上报里，`op` 为 `delete`，时间为这次删除发下的 HLC 时间戳。其他节点要等 [上报](上报.md) 和派发之后才去掉地址。灾备要等下一次整理。

### 例子

```javascript
await north.remove({ userId: '林夏', keys: ['电话'] })
```

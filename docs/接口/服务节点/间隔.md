## `setReportInterval`

通知中央改这台节点的上报间隔，并重启本机的定时上报。

### 签名

```javascript
await node.setReportInterval(reportIntervalMs)
```

### 参数

| 字段 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `reportIntervalMs` | 整数 | 是 | 不小于 1 的毫秒数。 |

### 返回

```javascript
{ reportIntervalMs: 10000 }
```

### 抛出

| 条件 | `message` |
| --- | --- |
| 不是不小于 1 的整数 | `上报间隔必须是不小于 1 的整数` |
| 中央没有这台节点，或它不是服务节点 | `没有这台节点`，或 `只有服务节点有上报周期` |

### 调用返回时

中央把这台节点的周期改成新值，把上次上报时刻记成现在，重试次数清零。通知之后、新周期生效前的空档不算漏报。本机定时器改为按新间隔调用 `report`。

灾备整理间隔不变。那是中央的 `drIntervalMs`。

### 例子

```javascript
await north.setReportInterval(10000)
```

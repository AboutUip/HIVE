## `close`

停掉定时上报和 HTTP 监听，并关闭本机存储。

### 签名

```javascript
await node.close()
```

### 参数

无。

### 返回

没有返回值。

### 抛出

存储已经关闭时，再次使用这个对象会得到 `库已关闭`。

### 调用返回时

监听停止。数据目录里的 `state.json` 还在，其中是最后一次提交之后的局面。用同一个 `dataDir` 再 `startService()`，会接着这些数据，并向中央登记新的 `主机:端口`。

若这个编号已经在中央挂失，再次启动会抛出 `这台节点已挂失，清空数据目录后用 join 重新加入`。见 [回来](../../方案/回来.md)。

### 例子

```javascript
await north.close()

const again = await startService({
  dataDir: './data/svc-a',
  token: '集群令牌',
  id: 'svc-a',
  name: '华北节点',
  region: '华北',
  central: link
})
```

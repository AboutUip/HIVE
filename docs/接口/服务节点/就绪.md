## `ready`

把对齐期间缓冲区里的地址补进本机索引，然后开始服务。

### 签名

```javascript
const { message } = await node.ready()
```

### 参数

无。节点编号是启动时中央分配并记在这个对象上的。

### 返回

```javascript
{ message: '西南节点已就绪' }
```

### 抛出

| 条件 | `message` |
| --- | --- |
| 这台节点不在对齐中 | `西南节点不在对齐过程中` |
| 中央认为它不在对齐中 | 同样是 `…不在对齐过程中` |

### 调用返回时

- 中央把这台节点改成正在服务，上次上报时刻改成现在，并清掉它的缓冲区。
- 本机索引补上缓冲区里的地址。
- 之后可以 `write`、`read`、`remove`。定时上报开始真正送出。
- 它仍不在任何灾备的负责范围里。要在中央那一侧的灾备声明里加上它，并再等一次整理。

### 例子

```javascript
const west = await startService({
  dataDir: './data/svc-new',
  token: '集群令牌',
  region: '西南',
  join: true,
  central: link
})

await west.ready()
await west.write({ userId: '林夏', entries: [{ key: '城市', value: '成都' }] })
```

## 结论

挂失节点恢复在线后，清空自己的数据，作为一台新节点重新加入。它使用新的身份。旧身份保持挂失。

## 过程

1. 清空这台机器上的旧数据。生产里要清空数据目录，再用加入的方式重新登记。
2. 按新节点对齐索引。见 [加入](加入.md)。
3. 中央分配新的编号。旧编号保持挂失。
4. 灾备已经把所有权交给接替节点。旧库不再是数据来源。

回来时若装入还没结束，先完成或回退这次装入，再把这台机器当成新节点。

## 例子

华北 `svc-a` 挂失，数据已装入华东。这台机器修好后清空数据目录，作为新节点加入，得到新编号。`svc-a` 仍是挂失。林夏的城市继续在华东，不从这台机器的旧文件里找回来。

## 边界

- 用旧编号再次启动，中央仍回答挂失。这台进程不能继续以旧编号服务。
- 当前装入若还涉及这台旧编号，要先处理完这次装入。
- 新编号不会自动进入灾备的负责范围。

调用见 [启动](../接口/服务节点/启动.md)。核对时见 [恢复](../核对/恢复.md) 里的重新加入。

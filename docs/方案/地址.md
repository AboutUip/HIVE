## 结论

每台节点在中央有稳定别名，也有当前 IP。地址里两样都记。普通访问直接使用 IP。IP 无法访问时，才拿别名向中央要一次当前 IP。

## 过程

1. 节点启动时，把这次可以连接的 `主机:端口` 登记到中央。生产里这就是它的 IP 字段。
2. 中央的节点记录和全局地址改成这个新地址。
3. 已经派发出去的地址副本仍用旧 IP，直到某次访问发现不通。
4. 读取发现 IP 不通时，拿别名向中央要一次当前 IP，更新本机持有的同一别名的地址，然后再连一次。
5. 不在每一次访问时都用别名绕到中央。

## 例子

华北原来登记在 `127.0.0.1:4001`。华东的地址副本也是这个 IP。华北重启后绑定到 `127.0.0.1:4008`，并向中央登记。华东下一次读林夏的城市时，先连 `4001`，连不上，再按别名 `svc-a` 向中央要到 `4008`，更新自己的地址副本，然后从 `4008` 取值。这次取值仍不写入华东的库。

## 边界

- 别名核对只发生在 IP 已经失败之后，并且只做一次。
- 核对之后仍然不可达，这次读取拒绝。
- 目标已经挂失或还在对齐时，请求停住，不把新地址当成可以读取的目标。
- 中央自己的地址变化，不在节点别名这条路径里解决。见 [中央](中央.md)。

# 文档

从这篇进入。一篇只讲一个题目。

每篇开头是同一张表：这篇讲什么、谁来读、先读哪篇、接着读哪篇。

方案篇的正文固定四节，顺序不变：**结论**、**过程**、**例子**、**边界**。方案篇不写函数名。没有单个符号的篇，例如 [进程](接口/进程.md)，也用这四节。

接口篇和核对篇里，每个符号固定六节，顺序不变：**签名**、**参数**、**返回**、**抛出**、**调用返回时**、**例子**。同一篇里有多个符号时，每个符号重复这六节。

| 树 | 用来 |
| --- | --- |
| 方案 | 确认数据留在哪、地址记什么、上报、灾备、挂失和所有权怎么转移。 |
| 接口 | 在生产里启动中央、服务节点、灾备，并调用本机服务节点。 |
| 核对 | 把整个集群放在一个进程里，对照方案。线上不用这组符号提供服务。 |
